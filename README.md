# Bible Languages Studio – personal copy (private)

**by Larry Dalton**

This repository is **private**. It holds my own copies of two English Bible translations for
[Bible Languages Studio](https://github.com/larrycd/bible-languages-studio), and a personal installer that includes them.
They are copyrighted and are for my own study only: **do not make this repository public, fork it, or add collaborators.**

| | |
|---|---|
| `my-translations/ESV.json` | English Standard Version – ESV® Bible, © 2001 by Crossway |
| `my-translations/CSB.json` | Christian Standard Bible®, © 2017 by Holman Bible Publishers |
| `installer/bible-personal.nsi` | NSIS script for the personal installer (the public 1.0.2 installer plus the two translations) |
| Releases | `BibleLanguagesStudio-Personal-Setup.exe` and `SHA256SUMS.txt` |

Converted on 14/11/2026 from my own PDF copies: all 66 books and 1,189 chapters of each, with Psalm titles as verse 0
(matching the Hebrew). Every verse lines up with the studio's Hebrew and Greek, apart from passages the translations
themselves add or omit (for example John 7:53–8:11, Mark 16:9–20, Romans 16:24).

## Install on a new computer

1. Sign in to GitHub as larrycd, open **Releases** and download `BibleLanguagesStudio-Personal-Setup.exe`.
2. Run it. It installs Bible Languages Studio 1.0.2 (per user, no administrator rights) and puts the ESV and CSB in
   `Documents\bible-languages-studio-my-translations`.
3. In the studio, choose ESV or CSB from the **English** menu on the Bible page.

The public studio, its installer and its GitHub releases never contain these translations.
